# Original artwork

All six artworks were created for Moonfall with the built-in image-generation tool on October 28, 2026. No ROMs, extracted Square Enix assets, or artwork from the reference repository are included. Generated originals are committed in `artwork/`; optimized WebP delivery assets are in `public/art/` so the game never relies on remote image services. See `ART-PROMPTS.md` for the generation prompts. Character and enemy names and designs are original. Final Fantasy IV is referenced only as a gameplay inspiration.


WebP copies are resized with nearest-neighbor sampling and encoded with Sharp for mobile delivery. Transparency is preserved. Fonts are Cormorant Garamond and DM Sans, bundled via Fontsource under the SIL Open Font License; package license files are retained in dependencies. UI icons are Lucide (ISC).
